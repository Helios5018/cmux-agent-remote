# 使用指南

安装与首次登录见 [README](../README.md)，启动配置与连接问题见 [部署指南](deployment.md)。

## 找到和管理会话

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| 首页 | `#/` | 按 Workspace → Pane → Surface 展开的总览 |
| 单 Workspace | `#/w/:workspaceId` | 只展开指定 workspace 的深链 |
| 会话 | `#/s/:surfaceId` | 查看画面、历史、输入和文件 |

首页支持搜索、折叠和“只看 Agent / 全部 surface”。折叠与筛选保存在当前浏览器中。cmux-sentinel 的用量表（`cx7d`、`go5h`、`grokcredits` 这类 hidden sentinel workspace）不显示，两种筛选下都不出现，和 cmux 自带侧栏的 USAGE 面板一致；要看用量数字仍回 cmux。顶栏与 workspace 角标汇总运行中和需要处理的会话；标题以真实 surface 名为主。普通 Shell 也能打开查看和输入。

状态用于判断何时接手：工作中、等待批准、等待输入、已回复未读、空闲、可能停滞、错误。没有 Hook 时由输出变化推断，空闲或画面静止不代表任务成功；完成情况仍需检查输出与产物。

可以新建 workspace、分屏和 surface，启动 Shell 或已配置的 Agent，也可以修改名称、关闭会话。名称修改会同步到 cmux。关闭会结束真实终端及其中的进程；单独关闭 surface 时不能关掉 workspace 的最后一个 tab，结束整个 workspace 应使用 workspace 的关闭操作。

## 查看终端与历史

会话页可切换自动、缩放或换行显示，调整字号，或进入沉浸显示。全屏 TUI 默认等比缩放，可放大后横向滚动；普通输出默认换行。

| 终端类型 | 回看方式 | 影响 |
| --- | --- | --- |
| 普通屏 | 向上滚动，到顶加载更早历史，也可点击加载按钮 | 更早历史为纯文本，可能受读取上限限制 |
| 全屏 TUI | 上一屏 / 下一屏按钮，或边界拖动、滚轮翻页 | 会同步翻动 Mac 上的真实程序画面，离开会话时自动回到底部 |

控制键条在手机上可以横向滚动。Ctrl+C 需要确认，发送一次按键；要退出 Agent 可点「Ctrl+C ×2」并确认，由服务端间隔 100 ms 连按两次。Pi 用 Esc 中断生成，首次 Ctrl+C 只清空输入，须在 500 ms 内再按一次才退出；Claude / Grok 空闲时也需要再按一次，Codex 空闲时一次即可退出。运行中或弹窗内的行为由 Agent 决定，发送后请核对画面。Pi 会话显示 Ctrl+P 用于切换模型，Codex 会话显示 ⌥↑ 用于打开排队消息和异步提问（电脑上也可直接按 Option+↑）。

## 输入、草稿与发送结果

草稿按会话保存在当前页面内存中。切换会话、回首页或断线重连不会丢失；刷新、关闭页面、主动登出或通过网页成功关闭会话会清除对应草稿。登录过期后重新登录可继续尚在内存中的草稿。正文不写入浏览器持久化存储或服务端数据库。

| 发送反馈 | 下一步 |
| --- | --- |
| 已发送到终端 | cmux 已确认输入，草稿清空；继续观察 Agent 的处理结果 |
| 请求明确被拒绝 | 草稿保留，按提示修正内容或重新登录 |
| 结果未知 | 草稿保留并暂时禁止重复发送；先查看终端，确认已接收后清除，或确认未接收后继续编辑 |
| 文本已写入，提交结果未知 | 若正文仍停在终端输入行，可点击“已核对，仅补发 Enter” |

创建 tab 后启动失败，会打开已创建的会话并显示提示。如果整个创建请求结果未知，先刷新结构树检查，避免重复新建。

## 文件与附件

会话页右上角“⋯ → 打开文件系统”开启文件页。手机通过“会话 / 文件”切换，宽屏可并排显示；文件区足够宽时显示上级目录、当前目录和当前项预览三列。路径面包屑可点击返回上级，菜单可跳到主目录或当前 Agent 工作目录。

文件模块以会话为入口，但可访问整台 Mac 上当前用户有权限的文件。每个会话在当前浏览器中独立保存目录标签、选中项、滚动位置和剪贴板。关闭模块会清空该会话的标签和剪贴板；再次开启从 Agent 工作目录进入，无法获取时使用主目录。

### 浏览和整理文件

- 支持当前目录筛选、递归文件名搜索、文本内容搜索；列表分页加载。隐藏文件默认显示，可在菜单切换。
- 支持文本、代码、Markdown 源文、图片、音视频预览和下载；音视频能否播放取决于浏览器编码支持，不进行转码。
- 支持新建文件 / 文件夹、重命名、复制地址、多选复制与剪切粘贴。同名拒绝覆盖，请改名后重试；当前不提供正文编辑。
- 剪切在粘贴成功后才移除源项目。复制或移动部分失败时，检查提示与目标目录；目标可能保留已完成的内容。
- 移到废纸篓需要一次确认，永久删除需核对清单并输入“删除”再次确认。确认期间文件变化需重新确认；永久删除不进入废纸篓。

单列点击文件夹进入，点击文件预览。三列布局中，中列点击切换当前项，右列点击进入，左列点击返回上一级。长按或菜单“选择文件”进入多选；手机可左右滑动切换目录标签。

| 快捷键 | 操作 |
| --- | --- |
| 方向键 / `h j k l` | 导航、进入或返回 |
| `Space`、`v` / `V` | 切换选中、连续选择 / 取消 |
| `Ctrl+A`、`Ctrl+R`、`Esc` | 全选已加载项、反选、取消 |
| `y`、`x`、`p` | 复制、剪切、粘贴 |
| `Y` / `X` | 清空剪贴板 |
| `d` / `D` | 移到废纸篓 / 永久删除 |
| `r`、`.`、`f` | 重命名、切换隐藏项、筛选 |
| `F1` / `~` | 快捷键说明 |

快捷键只在文件区获得焦点时生效，不接管终端输入框、播放器或确认弹窗。

### 把文件交给 Agent

输入框“＋”支持照片与视频、上传文件、选择 Mac 文件。电脑可拖入本机文件或粘贴截图；文件面板可插入当前项、多选插入或拖入输入框。

本机已有文件直接引用；手机或浏览器所在设备的文件先上传到服务所在 Mac。引用插入正文光标处，发送和复制选区时展开为带引号的绝对路径，保持文字与文件的顺序。点击引用可预览、复制路径、重试上传或移除。移除引用不会删除磁盘文件。

上传进行中或失败时不能发送。上传状态和草稿在切换会话时保留，刷新或登出后内存草稿清除。上传成功只表示文件已保存，Agent 是否能理解内容取决于其工具与模型能力。

| 常用限制 | 行为 |
| --- | --- |
| 上传 | 单文件最多 512 MiB，网页最多同时传输两个文件 |
| 文本预览与内容搜索 | 最多处理 128 KiB 的文本；搜索有时间和数量限制 |
| 图片预览与普通下载 | 最多 20 MiB；音视频播放支持分段读取与进度跳转 |
| 复制 | 最多 100 个源、递归 10000 项或 512 MiB；不复制软链接与特殊文件 |

已上传文件不会随会话关闭自动删除，可通过文件浏览器管理。删除后历史引用将失效；保存位置见 [部署指南](deployment.md#数据与权限)。精确接口限额见 [Agent 接入指南](agent-guide.md#文件与上传)。

## 查看 Git

进入仓库后，文件区显示当前分支、变更数和上游领先 / 落后数，文件与目录带状态标记。点击摘要展开概览、变更、分支与提交：

- 变更按冲突、未暂存、已暂存、未跟踪分组，支持 Diff 与文件内容。
- 分支列表用于浏览历史，不会切换工作区。提交支持分页、完整说明、文件清单与 Diff；合并提交与第一父提交比较。
- 进入时先显示本地信息，再后台 fetch 默认 remote，同仓库有 5 分钟冷却；概览支持手动刷新。fetch 不等待交互认证，失败保留本地远程跟踪信息并显示原因。
- 文件区打开时每 10 秒刷新本地状态，页面隐藏时暂停，回到窗口立即刷新。大型 Diff 会提示截断，二进制文件只显示状态。

Git 功能不执行 pull、checkout、暂存或提交；fetch 会更新远程跟踪分支，但不自动清理远程已删除分支。
